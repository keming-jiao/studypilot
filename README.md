# Study Pilot

AI-powered study companion for college courses: upload course materials to get an AI chat tutor, auto-generated quizzes, and personalized study plans.

Conceived by KJ and co-built with LJ in Spring 2026. Piloted with the BUAD 310 (Applied Business Statistics) students KJ tutored as a Peer Academic Leader at USC Marshall.

Live demo: https://studypilot-topaz.vercel.app

Tech stack: Next.js, TypeScript, Tailwind CSS, PostgreSQL (Supabase), Prisma, Claude API, deployed on Vercel.
